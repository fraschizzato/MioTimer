# MioTimer privacy statement

_Last updated: 27 September 2026_

MioTimer is designed as an offline Android application.

The current version:

- does not create user accounts;
- does not include advertising;
- does not include analytics or tracking SDKs;
- does not request the Android `INTERNET` permission;
- does not transmit saved timers, workout definitions or settings to a server.

Timer preferences and workout definitions are stored locally on the device using Android application storage.

Android may display a foreground-service notification while a timer is active. MioTimer may also use vibration and an audible tone when enabled by the user.

This statement describes the source code in this repository. If a future distribution adds online services, analytics, crash reporting or other data processing, this document must be updated before that version is released.
