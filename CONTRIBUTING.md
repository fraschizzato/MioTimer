# Contributing

Issues, bug reports and feature proposals are welcome.

MioTimer uses a source-available noncommercial license and the project owner may also offer separate commercial licenses. That dual-licensing model requires clear rights to every contribution included in the codebase.

For that reason, please do not assume that opening a pull request automatically makes it mergeable. External code contributions may require separate contributor terms before acceptance so that the project can continue to be distributed under both its public and commercial licensing models.

For small fixes, opening an issue first is the simplest approach.
